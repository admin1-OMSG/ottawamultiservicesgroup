OMSG — INSTALLATION DE LA PRÉSENTATION V5

À appliquer sur la V4 publiée dans le commit 0a9db75.
Cette archive contient uniquement les fichiers modifiés ou ajoutés, avec leurs chemins d’origine, sans dossier parent.

CE QUI CHANGE
- Photos d’illustration pour le résidentiel et le commercial.
- Pages plus aérées : forfaits principaux, détails dépliables et boutons visibles.
- Calculateur sur /pricing/estimate, avec reprise du forfait sélectionné.
- Politique des prix regroupée en rubriques dépliables.
- Prix, économies, taxes et connexion existante au formulaire CRM conservés.
La grille reste en version 2026-09-20-v4. V5 désigne la présentation.
Aucune migration Supabase, nouvelle dépendance ou variable d’environnement n’est nécessaire.

1. EXTRAIRE ET COPIER
Fermez le serveur local s’il est en cours d’exécution.
Extrayez le ZIP dans un dossier temporaire, puis copiez TOUT son contenu dans :
C:\Users\Dell\OneDrive\Desktop\OMSG-v2.5-clean\ottawamultiservicesgroup-main

Acceptez le remplacement des fichiers de même nom. Fusionnez les dossiers src et docs ; ne supprimez pas leurs autres fichiers.
Vérifiez que le fichier src\routes\pricing.estimate.tsx et le dossier src\assets\cleaning sont bien présents dans votre projet.

2. VÉRIFIER
Depuis PowerShell, dans le dossier du projet, exécutez séparément :

node scripts/test-cleaning-pricing.mjs
npm.cmd run build

Le premier doit annoncer 13 contrôles réussis. Si une commande échoue, corrigez le problème avant l’envoi.
Pour prévisualiser localement : npm.cmd run dev, puis ouvrez l’adresse indiquée dans PowerShell avec le chemin /pricing.

4. COMMIT ET ENVOI
Après réussite des vérifications, exécutez séparément :

git commit -m "Tarifs V5 : presentation illustree et calculateur separe"
git push origin main

Le push envoie le code à GitHub. Attendez ensuite la réussite du déploiement habituel de votre site.
