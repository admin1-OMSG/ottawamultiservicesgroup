Ottawa Multiservices Group CRM - PATCH v0.8.7
Portail client : facture professionnelle + téléchargement PDF + email amélioré

1) Copiez les dossiers src et supabase de ce patch à la racine de votre projet.
   Acceptez de remplacer les fichiers existants.

2) Installez jsPDF (nécessaire pour le vrai bouton "Télécharger PDF") :
   npm install jspdf@4.2.1

3) Redéployez la fonction email :
   npx supabase functions deploy send-crm-email --no-verify-jwt

4) Vérifiez le build :
   npm run build

5) Publiez :
   git add .
   git commit -m "feat: improve client invoices PDF and email layout"
   git push origin main

6) Après Vercel = Ready, rechargez le portail avec Ctrl+F5.

Aucune migration SQL n'est nécessaire.

Nouveautés :
- factures du portail affichées comme cartes professionnelles ;
- bouton Voir la facture ;
- bouton Télécharger PDF ;
- PDF avec client, lignes, sous-total, HST, total, payé, solde et paiements ;
- lien email ouvre directement la facture concernée ;
- email de facture reconstruit avec tableaux HTML compatibles Gmail/Outlook ;
- CTA email : Voir la facture et télécharger le PDF.
