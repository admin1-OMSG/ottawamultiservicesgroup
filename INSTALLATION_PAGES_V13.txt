1. COPIER
Fermez votre serveur local s'il est en cours (Ctrl+C).
Extrayez le ZIP, puis copiez son CONTENU dans :
C:\Users\Dell\OneDrive\Desktop\OMSG-v2.5-clean\ottawamultiservicesgroup-main
Acceptez le remplacement des fichiers et la fusion des dossiers src, scripts et docs.
Ne supprimez pas vos anciens dossiers et ne créez pas un second projet imbriqué.

2. VÉRIFIER DANS POWERSHELL
Depuis ce dossier, exécutez :

node scripts/test-contact-request.mjs
node scripts/test-marketing-consent.mjs
node scripts/test-cleaning-pricing.mjs
npm.cmd run build

Résultats attendus : 6 contrôles Contact, 9 contrôles de consentement, 24 contrôles tarifaires et compilation réussie.
Ces tests ne transmettent rien à votre CRM et n'envoient pas de courriel.
Utilisez npm.cmd si PowerShell bloque npm.ps1.

3. CONSULTER LES PAGES LOCALEMENT
npm.cmd run dev
Ouvrez l'adresse locale affichée dans le terminal, puis :
/terms
/privacy
/faq
/data-deletion
/contact

Vérifiez les versions EN/FR, puis choisissez Refuser dans la bannière.
Le lien « Préférences de confidentialité » du pied de page permet de revoir le choix.
La page Contact nécessite maintenant la vérification de l'adresse courriel.
Une demande réellement envoyée depuis votre navigateur utilise votre CRM réel ; ne soumettez qu'un message d'essai identifiable si vous souhaitez cette vérification.
Les messages seront dans la boîte des demandes, sous « Contact message » ou « Message de contact ».
Une demande Contact ne crée aucun devis officiel ni rendez-vous.
Arrêtez le serveur avec Ctrl+C.
