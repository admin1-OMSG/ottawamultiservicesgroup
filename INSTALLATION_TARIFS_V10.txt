6. PRÉPARER LE DEVIS RÉVISÉ
Un devis déjà enregistré ne reçoit pas automatiquement de nouvelles obligations.
Dans le CRM, ouvrir le devis concerné et cliquer sur :
« Préparer un nouveau devis depuis cette demande / Prepare a new quote from this request ».
Ce lien ouvre un NOUVEAU brouillon à partir de la même demande ; il ne modifie pas l’ancien devis et ne l’annule pas.

Dans le nouveau formulaire :
- Vérifier les montants, la visite couverte et la condition des quatre visites.
- Ouvrir « Prestations comprises dans le devis officiel ».
- Vérifier les pièces/surfaces, l’adresse, les tâches, les quantités et les options par visite.
- Ajuster le texte si une prestation particulière est convenue. Chaque rubrique commence par ## ; les tâches sont du texte lisible.
- Vérifier aussi l’annexe si vous modifiez les lignes tarifaires ou les quantités.
- Enregistrer le brouillon, relire, puis envoyer le nouveau devis au client.

Pour une demande antérieure à V10, les descriptions peuvent être proposées à partir des choix enregistrés et des descriptions actuelles. Un message l’indique dans le formulaire : vérifier avant émission. Aucun prix n’est recalculé pour cette opération.
Si la demande ne permet pas d’identifier le service ou les options, ou concerne des travaux spécialisés, saisir le périmètre convenu après étude / visite sur site. Le formulaire refuse d’enregistrer un nouveau devis de nettoyage sans annexe structurée renseignée.
Une demande antérieure à V8 ne reçoit pas automatiquement la condition des quatre visites : elle doit être revue si cette nouvelle offre doit être proposée.
Un devis déjà accepté ou signé reste intact ; toute nouvelle proposition doit être présentée distinctement au client.

7. CONTRÔLER CÔTÉ CLIENT
Actualiser le portail avec Ctrl + F5 et ouvrir le NOUVEAU devis.
- « Voir les prestations comprises à chaque visite » est indépendant des calculs.
- Le tableau des montants comporte « Voir les prestations » à chaque visite lorsque l’échéancier et l’annexe sont présents.
- Cliquer sur la première visite : tâches de base + toutes les options prévues pour cette visite.
- Cliquer sur la quatrième : mêmes tâches de base + options récurrentes uniquement ; le crédit ne diminue pas le travail convenu.
- Vérifier produits, limites, exclusions, checklist et photos uniquement avec autorisation préalable.
- Les conditions et notes restent consultables dans une rubrique séparée.
- L’annexe est aussi disponible dans l’écran de signature.

Le courriel nouvellement envoyé contient l’annexe complète et le lien sécurisé vers le devis. Utiliser votre propre adresse pour un test.
Les anciens courriels ne changent pas. La simple consultation n’envoie aucun message.
L’annexe est affichée dans la langue d’émission du devis ; ses formulations enregistrées ne sont pas remplacées par une traduction automatique après signature.
La version V10 ne suit pas automatiquement l’exécution des tâches ni les visites réellement effectuées : ces opérations restent celles du CRM et de votre suivi qualité.
