5. METTRE À JOUR LE COURRIEL DANS SUPABASE
Le push GitHub ne déploie pas automatiquement cette fonction dans la configuration du projet examinée. Depuis le même dossier PowerShell :

npx.cmd supabase@latest login

Suivez la connexion dans votre navigateur. Il n’est pas nécessaire de transmettre votre jeton ou vos clés dans le chat.
Pour retrouver les projets accessibles :

npx.cmd supabase@latest projects list

Repérez la référence du projet SUPABASE UTILISÉ PAR LE SITE OMSG. Elle correspond aussi à la partie après /project/ dans l’adresse de votre tableau de bord Supabase.
Remplacez VOTRE_REFERENCE_PROJET par cette référence exacte dans la commande suivante :

npx.cmd supabase@latest functions deploy send-crm-email --project-ref VOTRE_REFERENCE_PROJET --use-api

Cette commande déploie uniquement send-crm-email et assemble son module partagé, sans Docker. Attendez la confirmation de réussite.
Conservez le fichier supabase/config.toml et les secrets déjà en place ; cette livraison ne demande pas de les remplacer.
Ne lancez pas de migration SQL ni de déploiement de toutes les fonctions.

Documentation officielle :
https://supabase.com/docs/guides/functions/deploy
https://supabase.com/docs/reference/cli/supabase-functions-deploy

6. VÉRIFIER UNE NOUVELLE DEMANDE
Ouvrez :
https://www.ottawamultiservicesgroup.com/pricing/estimate?audience=residential&plan=weekly

Sélectionnez le profil 3 chambres, 1,5 salle de bain, jusqu’à 1 500 pi², Ontario.
Ajoutez réfrigérateur 1, four 1, plinthes 1, vitres intérieures 2, draps 2.
Par défaut, chaque option est pour la première visite seulement.
Résultat attendu : première visite 423,75 $ TTC ; suivantes 189,84 $ TTC.
Choisissez À chaque visite uniquement pour les draps : suivantes 212,44 $ TTC ; budget mensuel moyen 814,67 $ avant taxes. La première visite reste à 423,75 $ TTC.

Envoyez une nouvelle demande avec votre propre courriel, puis vérifiez :
- la réception de la notification administrateur ;
- le Résumé des choix / Selection summary, sans Selection JSON ;
- la fréquence de chaque option et les deux totaux ;
- les mêmes données lisibles dans la fiche de demande du CRM.

Les courriels déjà reçus ne sont pas modifiés. Les anciennes demandes du CRM conservent leurs montants et sont affichées lisiblement, sans recalcul rétroactif.
Si le site est à jour mais que le courriel garde l’ancienne présentation, vérifiez l’étape 5 et créez une nouvelle demande de contrôle.

Les aperçus docs/pricing-preview/quote-email-v6-*.html utilisent des coordonnées fictives et illustrent une notification ADMINISTRATEUR, pas un devis officiel envoyé au client.
